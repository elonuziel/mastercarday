# 💳 Mastercard Day Israel - Benefits & Deals Catalog

אתר אינטרנט וסורק אוטומטי המרכז את כל ההטבות, ההנחות וקודי הקופון של **Mastercard Day** (יום מאסטרקארד בישראל הנחגג בכל 10 בחודש), מונגש לציבור ומפורסם ב-GitHub Pages.

---

## ✨ תכונות מרכזיות

- ⏱️ **ספירה לאחור חיה ל-10 בחודש:** טיימר אנימטיבי המחשב את הזמן שנותר למועד פתיחת ההטבות ב-10:00 בבוקר (או מציין כשההטבות פעילות כעת).
- 📋 **העתקת קוד קופון בלחיצה אחת:** כפתור ייעודי להעתקת קוד הקופון (למשל `MASTERCARDAY`) עם התראת Toast צפה ונוחה.
- 🔗 **שיתוף הטבה ישיר:** אפשרות לשיתוף קישור עמוק לכל הטבה (`#deal-id`) עם גלילה והדגשה אוטומטית.
- 🗂️ **סינון חכם לפי קטגוריות:** תיירות ונופש, קולינריה ומסעדות, אופנה ולייף סטייל, חשמל וטכנולוגיה, לבית ולמשפחה, צרכנות ופנאי.
- 🔍 **חיפוש מיידי:** חיפוש בזמן אמת לפי שם מותג, כותרת, קוד קופון או תנאים.
- 📊 **תצוגה כפולה:** מעבר מהיר בין תצוגת כרטיסים גרפית (Grid) לטבלת נתונים קומפקטית (Table).
- 🌙 **מצב כהה / בהיר (Dark & Light):** תמיכה מלאה בערכת נושא כהה עם זיהוי העדפת מערכת ושמירה ב-LocalStorage.
- 📥 **ייצוא נתונים:** קובצי [data/deals.json](data/deals.json) ו-[data/deals.csv](data/deals.csv) (תואם Excel בעברית עם UTF-8 BOM).
- ⚡ **Zero-Build (ללא שלב הידור):** בנוי ב-HTML5 סטנדרטי, Tailwind CSS ו-Vanilla JavaScript. פועל מיידית ב-GitHub Pages ללא צורך ב-Node.js.

## 🛠️ התקנה והרצת הסורק מקומית

### 1. דרישות מוקדמות
ודא שמותקן Python 3.10 ומעלה, והתקן את החבילות:
```bash
pip install -r requirements.txt
```

### 2. הפעלת הסריקה
הרצת הסקריפט תוריד את עמוד המבצעים הרשמי, תחלץ את כל רכיבי ההטבות, ותשמור אותם לתיקיית `data/`:
```bash
python scraper.py
```

*הערה טכנית:* עמוד המבצעים של מאסטרקארד מוגן על ידי מערכת הסינון של Akamai Bot Manager (`403 Access Denied`). הסורק משתמש בספריית `curl_cffi` המדמה פרופיל TLS של דפדפן Chrome אמיתי ומבצעת את הסריקה תוך שניות בודדות ללא צורך בהתקנת דפדפן כבד.

## 🌐 פריסה ל-GitHub Pages

הפרויקט מוכן לפריסה ישירה:
1. פתח את הגדרות המאגר ב-GitHub: **Settings** -> **Pages**.
2. תחת **Build and deployment** בחר ב-**Deploy from a branch**.
3. הגדר את הענף **`main`** ואת התיקייה **`/(root)`** ולחץ **Save**.
4. האתר יפורסם אוטומטית בכתובת:
   `https://<username>.github.io/mastercarday/`

תהליך ה-GitHub Action (`.github/workflows/scrape.yml`) ירוץ אוטומטית בכל יום ראשון וכן בימים ה-9 וה-10 בכל חודש, יעדכן את הנתונים ויבצע commit & push שיעדכנו את האתר מיידית!
